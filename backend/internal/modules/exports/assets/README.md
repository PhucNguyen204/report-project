# Vietnamese report font

`NotoSans-Regular.ttf` is the unmodified Noto Sans regular font from the official Noto fonts repository:
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf

Downloaded 2026-11-12. The accompanying `OFL.txt` is the upstream SIL Open Font License 1.1 from:
https://github.com/notofonts/noto-fonts/blob/main/LICENSE

The font is embedded in the Go binary so report workers do not depend on installed system fonts or network access.
